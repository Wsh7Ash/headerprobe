- Unit tests covering core logic and CLI behavior.
- CI workflow (install + pytest) on push and pull request.
- README, docs/ARCHITECTURE.md, docs/USAGE.md, docs/PROJECT_SPEC.md, examples,
  and captured demo output in `results/demo-output.txt`.
